🔌 Connections

All platforms are grouped under each YouTube account. Select an account to manage its YouTube channels, Facebook Pages and Instagram accounts.

✨ Gemini (Google AI)

Separate Google OAuth connection for video analysis and metadata generation. Multiple accounts supported.

Google Cloud: Enable the Generative Language API in the project shown by your OAuth client. If the OAuth app is in Testing mode, add each Gemini Google account under Test Users.

🔵 OpenAI / ChatGPT

Connect your OpenAI API key to enable ChatGPT-powered metadata generation. Get your key from platform.openai.com/api-keys.

🌐 Option 1: Browser Login (Username & Password) Opens a clean Chrome window to chatgpt.com. Enter your email/username & password directly in the browser. Zero credential storage; session is preserved locally.
🔑 Option 2: OpenAI API Key (Optional)

Use your OpenAI API key directly if you prefer API usage over browser automation.

🟣 Anthropic / Claude

Connect your Anthropic API key to enable Claude-powered metadata generation. Get your key from console.anthropic.com.
