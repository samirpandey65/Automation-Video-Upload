📋 Setup Guide

Follow each section to connect YouTube, Gemini AI, Facebook/Instagram, Telegram notifications, and OpenAI/ChatGPT.

GOOGLE CLOUD + YOUTUBE API
You need a Google Cloud project with the YouTube Data API v3 enabled and a Desktop OAuth client to connect YouTube channels.
0 / 6 steps completed
01Create a Google Cloud Project
  1. Go to console.cloud.google.com ↗ and sign in with your Google account.
  2. Click the project dropdown at the top → New Project.
  3. Enter a name like YouTubeUploader and click Create.
  4. Make sure the new project is selected in the top dropdown before continuing.
02Enable YouTube Data API v3
  1. In Google Cloud Console, go to APIs & Services → Library.
  2. Search for YouTube Data API v3 and click it.
  3. Click Enable.
Without this API enabled, YouTube uploads and channel sync will fail with a 403 error.
03Configure OAuth Consent Screen
  1. Go to APIs & Services → OAuth consent screen.
  2. Select External and click Create.
  3. Fill in App name (e.g. YouTube Uploader), support email, and developer email.
  4. On the Scopes step, click Add or Remove Scopes and add:
    https://www.googleapis.com/auth/youtube.upload
    https://www.googleapis.com/auth/youtube.readonly
  5. On the Test users step, add your Google account email.
  6. Click Save and Continue through all steps.
Keep the app in Testing mode. You do not need to publish it for personal use.
04Create Desktop OAuth Client
  1. Go to APIs & Services → Credentials.
  2. Click + Create Credentials → OAuth client ID.
  3. Application type: Desktop app.
  4. Name it YouTube Uploader Desktop and click Create.
  5. Click Download JSON — this is your client_secret.json.
  6. Save it somewhere safe on your computer.
✅ This JSON file is what you upload in the Connections page when adding a YouTube account.
05Connect YouTube Account in the App
  1. Open Connections ↗ → click + Add YouTube Account.
  2. Enter an account name (e.g. your channel name).
  3. Click Browse and select the client_secret.json you downloaded.
  4. Click Connect with Google — a browser window will open.
  5. Sign in with the Google account that owns your YouTube channel.
  6. Select the channel when prompted and click Connect Selected Channel.
06Test & Sync
  1. On the Connections page, click ⚡ Test next to your YouTube account.
  2. Go to Dashboard ↗ and click Sync YouTube to pull your existing videos.
  3. Go to Upload ↗, select a video folder, and try a test upload.
✅ If the test passes, your YouTube connection is fully working.
GOOGLE GEMINI AI
Gemini is used for automatic video analysis and metadata generation. It uses a separate Google Cloud OAuth client from YouTube — you can use the same project or a different one.
0 / 5 steps completed
01Enable Generative Language API
  1. Go to Google Cloud Console ↗ and select your project.
  2. Go to APIs & Services → Library.
  3. Search for Generative Language API and click Enable.
  4. Also enable Cloud AI Platform API if prompted.
If you get a 403 error when testing Gemini, this API is not enabled in the correct project.
02Configure OAuth Consent Screen for Gemini
  1. Go to APIs & Services → OAuth consent screen.
  2. If not already done, set up External consent screen with your email.
  3. Add these scopes:
    https://www.googleapis.com/auth/generative-language.retriever
    https://www.googleapis.com/auth/cloud-platform
    openid, email, profile
  4. Under Test users, add the Google account you will use for Gemini.
03Create Desktop OAuth Client for Gemini
  1. Go to APIs & Services → Credentials → + Create Credentials → OAuth client ID.
  2. Application type: Desktop app.
  3. Name it Gemini Desktop and click Create.
  4. Download the JSON — this is your Gemini client_secret.json.
✅ You can use the same client_secret.json as YouTube if they are in the same Google Cloud project.
04Connect Gemini Account in the App
  1. Open Connections ↗ → scroll to ✨ Gemini section.
  2. Click + Add Gemini Account.
  3. Enter an account name and browse to select the Gemini client_secret.json.
  4. Click Connect with Google and complete sign-in in the browser.
05Test Gemini Connection
  1. On the Connections page, click ⚡ Test next to your Gemini account.
  2. A successful test shows the connected email and detected model.
  3. Go to Upload ↗, select a video, and click 🤖 Analyze with AI to test metadata generation.
Large videos (>18 MB) are uploaded via the Gemini Files API automatically. Very large videos may take 1–2 minutes to process.
FACEBOOK + INSTAGRAM
Meta requires a Facebook Developer App with Facebook Login for Business to publish videos and Reels to Facebook Pages and Instagram.
0 / 7 steps completed
01Create a Meta Developer App
  1. Go to developers.facebook.com/apps ↗ and sign in.
  2. Click Create App.
  3. Choose use cases related to Page management and Instagram content publishing.
  4. Enter app name VideoUploader, contact email, and business portfolio if required.
  5. Click Create App.
02Get App ID and App Secret
  1. In your app dashboard, go to App settings → Basic.
  2. Copy the App ID (visible by default).
  3. Click Show next to App Secret and copy it.
Never share your App Secret publicly or commit it to Git.
03Enable Facebook Login for Business
  1. In your app dashboard, find Facebook Login for Business and click Set up.
  2. Go to its Settings tab.
  3. Under Valid OAuth Redirect URIs, add:
    http://localhost:8080/api/meta/oauth/callback
  4. Click Save Changes.
The redirect URI must exactly match the address you use to open this app in your browser.
04Create a Business Login Configuration
  1. Go to Facebook Login for Business → Configurations.
  2. Click Create configuration.
  3. Name it VideoUploader, select General login variation and User access token.
  4. Save and copy the Configuration ID — you will need this when connecting in the app.
05Configure Required Permissions

Add these permissions to your configuration:

PermissionPurpose
pages_show_listList your Facebook Pages
pages_read_engagementRead Page info
pages_manage_postsPublish to Facebook Pages
instagram_basicIdentify linked Instagram account
instagram_content_publishPublish Instagram Reels
06Add Yourself as Test User
  1. Go to App roles → Roles.
  2. Under Testers, click Add Testers and add your Facebook profile.
  3. Accept the tester invite from your Facebook notifications.
While the app is in Development mode, only added testers can authorize it.
07Connect Meta Account in the App
  1. Open Connections ↗ → expand a YouTube account → click + Connect Facebook Page.
  2. Enter your Meta App ID, App Secret, and Configuration ID.
  3. The Redirect URI is auto-filled — make sure it matches what you added in step 03.
  4. Click Continue with Meta and complete Facebook authorization in the popup.
  5. Select your Facebook Page when prompted and click Save Connection.
✅ After connecting, click ⚡ Test to verify the Page token is working.
TELEGRAM NOTIFICATIONS
Get instant Telegram messages when uploads complete, fail, or tokens are expiring. Takes about 2 minutes to set up.
0 / 4 steps completed
01Create a Telegram Bot via @BotFather
  1. Open Telegram and search for @BotFather — look for the blue ✅ verified checkmark.
  2. Or open directly: t.me/BotFather ↗
  3. Send /newbot to BotFather.
  4. Enter a display name, e.g. YouTube Uploader Notifications.
  5. Enter a username ending in bot, e.g. YouTubeUploaderNotify_bot (no dots, no spaces).
  6. BotFather will reply with your Bot Token — copy it immediately.
The Bot Token looks like: 123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
02Start Your Bot & Get Your Chat ID
  1. Search for your new bot by its username in Telegram and click Start — this is required before it can message you.
  2. Open @userinfobot ↗ (verified bot) and send /start.
  3. It will reply with your Id: number — this is your Chat ID.
✅ For a group/channel: add your bot to the group, then use @userinfobot inside the group. Group IDs start with -100.
03Configure in the App
  1. Open Settings ↗ → scroll to 📱 Telegram Notifications.
  2. Paste your Bot Token into the Bot Token field.
  3. Paste your Chat ID into the Chat ID field.
  4. (Optional) Enter your Application URL (e.g. http://localhost:9000 or your public domain) to include clickable app links in Telegram notifications.
  5. Check Enable Telegram notifications.
  6. Click 📨 Send Test Message — you should receive a message in Telegram instantly.
  7. Click 💾 Save Telegram Config.

OPENAI / CHATGPT
Connect your OpenAI API key to enable ChatGPT-powered features. You need an OpenAI account with API access (not just a ChatGPT subscription).
0 / 3 steps completed
01Get an OpenAI API Key
  1. Go to platform.openai.com/api-keys ↗ and sign in.
  2. Click + Create new secret key.
  3. Give it a name like YouTubeUploader and click Create secret key.
  4. Copy the key immediately — it starts with sk- and is only shown once.
You need a paid OpenAI API account (separate from ChatGPT Plus). Add billing at platform.openai.com/billing ↗.
02Connect OpenAI in the App
  1. Open Connections ↗ → scroll to 🔵 OpenAI / ChatGPT.
  2. Paste your API key into the API Key field.
  3. Select a model — gpt-4o is recommended for best quality.
  4. Check Enable OpenAI / ChatGPT.
  5. Click ⚡ Test Connection to verify the key works.
  6. Click 💾 Save OpenAI Config.
✅ The API key is stored securely in the local database and never sent anywhere except OpenAI's API.
