Setup Guide

Use this page to connect accounts and understand re-authentication alerts.

📺 YouTube / Google

  1. Open Connections → Add YouTube Account.
  2. Select the Google OAuth client JSON and complete Google sign-in.
  3. Select the channel and save the connection.
  4. The uploader tracks a local re-auth reminder from the last successful authentication. This is a tracking reminder, not a guaranteed Google token-expiry date.
  5. If Google returns invalid_grant, the account is immediately marked RE-AUTH REQUIRED and scheduled work is paused for that account until reconnect.
Missing credentials: the channel/account record is preserved; only authentication-dependent scheduler work is paused.

📘 Meta — Facebook + Instagram

  1. Open Connections → Connect Meta Account.
  2. Enter Meta App ID, App Secret and Facebook Login for Business Configuration ID.
  3. Use http://localhost:8080/api/meta/oauth/callback as the redirect URI.
  4. Complete Meta authorization and select the Facebook Page when more than one Page is returned.
  5. Each connected Page is stored separately, so multiple Meta accounts/Pages can be tested.

🔔 Re-authentication tracking

The dashboard shows an Action Required panel when an account is actually marked for re-authentication or its configured reminder reaches the final 2 days. The Connections page shows the account, last verification time, and remaining reminder days.

Default reminder window: 7 days after a successful Google connection/test. A successful reconnect resets the reminder window.
