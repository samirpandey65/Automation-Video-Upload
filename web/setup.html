01Create Meta Developer App
  1. Open Meta My Apps ↗ and sign in.
  2. Click Create App.
  3. Choose the relevant Page management and Instagram content use cases, or the appropriate business integration option if prompted.
  4. Enter app name Video uploader, contact email and business portfolio if required.
  5. Create the app. If you already have the Video uploader app, reuse it instead of creating duplicates.
02Get App ID and App Secret
Go to My Apps ↗ → your app → App settings → Basic. Copy the App ID and securely store the App Secret. Never commit it to Git or expose it in frontend JavaScript.
03Enable Facebook Login for Business
In the app Dashboard or Use cases, add Facebook Login for Business. Open its Settings and enter this exact Valid OAuth Redirect URI:
http://localhost:9000/api/meta/oauth/callback
Save changes. Use the same host and port in your browser and backend. Localhost works only on the computer running the app.
04Create Business Login Configuration
Open Facebook Login for Business → Configurations → Create configuration. Use name VideoUploader, General login variation and User access token if these options are available. Save and copy the Configuration ID (different from App ID). Your previously shown configuration ID was 1174998162132410; verify it is still the active one.

06Check Facebook Page Access
Open Facebook Pages ↗. Your screenshot showed CineAd Studio, DealDhoondo and Bachpan Express. For each Page open Settings → Page access, and confirm your Facebook profile has the necessary Facebook access and content permissions. If the Page belongs to a business portfolio, verify its asset assignment in Business Settings ↗.
07Link Instagram Professional Account
Convert Instagram to a Business or Creator account if needed. For the Instagram API with Facebook Login flow, link it to the appropriate Facebook Page. Check in Meta Business Settings ↗. Facebook Page connection can be tested first even if Instagram is not yet linked.
08Check App Roles and Testing Access
Open your app → App roles → Roles. Your earlier screenshot already confirmed your profile is an Administrator. While the app is Unpublished, test with an authorized role account. You do not need to add yourself as Tester again.
09Test User Token and Granted Permissions
  1. Open Graph API Explorer ↗.
  2. Select your Video uploader app and User Token.
  3. Select the required permissions, then click Generate Access Token and approve access.
  4. Submit the following requests one at a time:
GET /me?fields=id,name
GET /me/permissions
Check that pages_show_list has status granted. If not, reauthorize with the right configuration and Page access.

11Connect OmniCast Studio
Open Local Connections ↗ → Connect Meta Account. Enter Account Name, App ID, App Secret, the correct Configuration ID and the exact callback URI. Complete Facebook authorization, select a Page if prompted, then check Connection API ↗. A saved account must appear in the connections array. If it remains empty, check the OAuth callback and Page API response.
12Test Publishing and Prepare for Production
First run Test Connection. Select a short test video and a Facebook Video, Facebook Reel or Instagram Reel destination. Review the target account and caption, then explicitly approve publishing. Your backend requires approved: true. For external users, complete applicable App Review, Advanced Access, privacy requirements and publishing prerequisites via Meta App Dashboard ↗. Publishing an app does not automatically grant all permissions.
