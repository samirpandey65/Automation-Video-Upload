📱 Telegram Notifications

Get instant Telegram messages for uploads, failures, and token expiry. Create a bot via @BotFather to get your Bot Token, then message your bot and use @userinfobot to get your Chat ID.

Notifications sent for: ✅ YouTube upload complete  ❌ Upload failed  🤖 Scheduled upload  📘 Facebook/Instagram publish  ⚠️ Token expiry (max once per 24h)

💾 Backup & Restore

Export the full database (schedules, channels, connections, video library) as a .db file. Import a backup to restore all settings. The app will save an automatic pre-restore backup before overwriting.

🔑 YouTube OAuth & Channel Authentication

Authentication uses Desktop OAuth configured via credentials/client_secret.json. Tokens and refresh keys are securely encrypted in Windows Credential Manager.

✅ Desktop OAuth client is loaded from credentials/client_secret.json.

🛡️ Security & Privacy

All videos, hashes, and transcripts remain strictly on your local disk (data/uploader.db). Never commit or share your credentials/client_secret.json or OAuth tokens.

🔐 Local Users

Only signed-in users can access the uploader. Admin can create additional editor logins.
